# Anaesthetic Insights

I want to build an app that will help anaesthetic trainees understand the physics, physiology and pharmacology underpinning anaesthetic practice. The app should provide information mapped to the FRCA primary and final exam curriculums. Information should be presented clearly, with diagrams where appropriate. The diagrams should be animated to demonstrate principles where appropriate. Please use reliable sources for all information, such as BJA Education. Each section should have a summary at the end with key learning points
